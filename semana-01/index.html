1

Para el Aprendizaje Práctico de este domingo

Fíjate en la forma exacta de escribir Go: dónde van (y dónde no) los paréntesis, las llaves y los dos puntos; qué hace cada símbolo (=, ==, :=, &, *); y cuántas veces gira un for.

Una pista, no la pregunta. El cuestionario vence el domingo 1 de noviembre.

Tres ideas para llevarse

  • En Go el tipo va después del nombre: var edad int. Lo que no cambia se declara con const.
  • = asigna, == compara (también textos) y := declara y asigna a la vez.
  • if, switch y for van sin paréntesis y con llaves. for es el único ciclo de Go.

Le pedimos a la IA un menú en Go y lo leemos línea por línea con lo que sabemos.

Le pedimos un menú a la IA

Escribe en Go un programa de consola para gestionar libros electrónicos: un menú con 1) agregar libro, 2) ver resumen y 3) salir, que se repita hasta elegir salir. Máximo 3 libros. Usa for, switch e if.

Para interpretar su respuesta

  • ¿Por qué fmt.Scan recibe &opcion y no opcion?
  • ¿Por qué ningún case termina en break?
  • ¿Qué pasaría si en la opción 3 cambiamos return por break?

Lo que respondió, leído con la teoría

for {
    var opcion int
    fmt.Scan(&opcion)
    switch opcion {
    case 1:
        if cantidad == limite {
            fmt.Println("Catálogo lleno")
        } else { /* agrega el libro */ }
    case 2:
        fmt.Println("Libros:", cantidad)
    case 3:
        return
    default:
        fmt.Println("Opción no válida")
    }
}
  • &opcion es la dirección de la variable: Scan la necesita para guardar lo que escribes.
  • En Go un case no cae en el siguiente: no hace falta break.
  • return termina el programa. Un break ahí saldría solo del switch y el menú nunca terminaría.

Código completo: semana-01/ejemplos/menu/main.go.

Decidir: else if y switch

if nota >= 9 {
    fmt.Println("Excelente")
} else if nota >= 7 {
    fmt.Println("Aprobado")
} else {
    fmt.Println("Reprobado")
}

Se ejecuta solo la primera rama verdadera, de arriba abajo.

switch formato {
case "ebook", "pdf":
    fmt.Println("digital")
case "tapa dura":
    fmt.Println("físico")
default:
    fmt.Println("desconocido")
}

Sin paréntesis ni break. Varios valores en un case, separados por comas.
