Para el Aprendizaje Práctico de este domingo

Fíjate en la firma completa de una función: la palabra clave con que empieza, dónde va cada tipo, cómo se escriben varios retornos y cuántos argumentos necesita la llamada. Y en el módulo: qué comando lo crea, qué se importa y qué hay que descargar.

Una pista, no la pregunta. El cuestionario vence el domingo 8 de noviembre.

Tres ideas para llevarse

  • Una función se declara con func, el nombre, los parámetros (nombre y luego tipo) y el tipo de retorno: func area(ancho, alto float64) float64.
  • Varios retornos van entre paréntesis y separados por comas, (int, bool), y se reciben en el mismo orden: total, ok := f().
  • Un paquete es una carpeta. Se importa por su ruta, "tienda/inventario", y desde fuera solo se ve lo que empieza con mayúscula.

¿Qué imprime este programa?

func precioFinal(precio float64,
    cantidad int) (float64, bool) {
    total := precio * float64(cantidad)
    return total, total > 50
}

func main() {
    t, envioGratis := precioFinal(12.5, 4)
    fmt.Println(envioGratis, t)
}
  1. true 50
  2. false 50
  3. 50 false
  4. No compila

Sigue los valores, paso a paso

PasoQué pasaValor
112.5 se copia en precio y 4 en cantidadprecio = 12.5 · cantidad = 4
2float64(cantidad) convierte el entero para poder multiplicartotal = 50
3total > 50: 50 no es mayor que 50false
4Vuelven en orden: el 1.º a t, el 2.º a envioGratist = 50 · envioGratis = false
5Println imprime en el orden en que recibe los argumentosfalse 50

Respuesta: false 50. El orden de los retornos lo fija la firma; el orden de lo impreso, la llamada a Println. Y Go no multiplica float64 por int sin convertir.

Le pedimos un inventario a la IA

Organiza en Go un pequeño inventario: un módulo llamado tienda con un paquete inventario que tenga una función para agregar unidades, otra que diga si alcanza para un pedido y cuántas faltan, y una validación interna que no se pueda usar desde fuera. Escribe también el main que lo usa.

Para interpretar su respuesta

  • ¿Por qué Disponible empieza con mayúscula y validar no?
  • ¿Qué escribe main en el import: el archivo o la carpeta?
  • ¿Qué pasa con lo que devuelve Agregar si no lo guardamos?

Lo que respondió, leído con la teoría

// inventario/inventario.go
package inventario

func Agregar(unidades int) int { … }
func Disponible(pedido int) (bool, int) {
    if pedido <= Stock {
        return true, 0
    }
    return false, pedido - Stock
}
func validar(unidades int) bool {
    return unidades > 0
}
  • Mayúscula: se exporta, y main la llama como inventario.Disponible(18). validar queda oculta.
  • main importa "tienda/inventario": el módulo más la carpeta, nunca inventario.go.
  • Llamar sin guardar compila, pero el total se pierde. Para usarlo: total := inventario.Agregar(5).

Código completo: ejemplos/inventario (go run .).

Qué pasa en una llamada

  • duracion se copia en minutos: son dos variables distintas.
  • Entre enteros, / descarta los decimales y % da el residuo.
  • Vuelven en el orden de la firma: el 1.º a h, el 2.º a m.
  • Al terminar, minutos desaparece. En main quedan 3 y 20.

Otros tipos de funciones

func sumarMontos(montos ...float64) float64 {
    total := 0.0
    for _, m := range montos { total += m }
    return total
}
sumarMontos(4.5, 3, 2.5)   // 10
triple := func(x int) int { return x * 3 }
aplicar(7, triple)          // 21
func generadorDeTurnos() func() int {
    siguiente := 0
    return func() int { siguiente++; return siguiente }
}
turno := generadorDeTurnos()
turno(); turno(); turno()   // 1, 2, 3
  • Variádica: ... acepta cualquier cantidad de argumentos del mismo tipo, también ninguno.
  • Anónima: una función sin nombre guardada en una variable y pasada como argumento, como una lambda.
  • Closure: la función devuelta recuerda siguiente entre llamadas.
